# Memory investigations

`optimization_baseline.py` records the existing immutable optimization inputs. `memory_configuration_screen.py` implements the historical bounded dense-memory screen and reusable stage functions. Active crop/alignment workflows still import those functions.

Use the command's help and [workflow reference](../../README.md). No screen or GPU pilot is authorized by moving these files. New evidence belongs in the external archive; old manifests and model settings remain unchanged.
