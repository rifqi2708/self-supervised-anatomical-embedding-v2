# Publication analysis and review

Cycle-error plots, coordinate/export diagnostics, cross-method comparisons and anatomical outcome inspection belong here. Input evidence remains in the canonical external archive; analysis must preserve run provenance and explicit denominators.

Anatomical review is distinct from mask QC and cycle consistency. Existing scientific gates and output locations are unchanged. Consult the analysis commands in [workflow reference](../README.md) and the [anatomical review guide](REVIEWED_ANATOMICAL_REVIEW.md).
