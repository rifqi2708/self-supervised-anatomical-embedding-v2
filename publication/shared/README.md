# Publication shared support

Coordinate conversions, reviewed matching contracts, sealed evidence and the method-independent checksum helper support multiple publication stages. Root `shared/` contains cross-project model interfaces and compatibility plumbing.

See [preparation](REVIEWED_MATCHING_PREPARATION.md) and [implementation](REVIEWED_MATCHING_IMPLEMENTATION.md). Source relocation changes implementation signatures honestly; it does not mutate frozen evidence or grant scientific-pilot approval.
