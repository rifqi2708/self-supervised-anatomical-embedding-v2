# Master project scripts

Earlier training loops, model-understanding code, single-cycle examples and data-preparation diagnostics retain their existing settings. Some are interactive scripts with fixed external input paths rather than command-line tools. Inspect settings before execution; importing an old runner may execute work.

Use [master workflow](../README.md), inherited [training reference](../../resources/training.md), and original configuration/data recovery sources. Shared model interfaces are imported from root `shared/`; `sam/` remains unchanged.
